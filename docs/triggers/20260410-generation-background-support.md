## Problem Statement

편집 화면에서 목차·개요 또는 원고를 생성하는 사용자가 생성을 요청했을 때, 생성이 완료될 때까지 다른 작업을 할 수 없고 백그라운드 생성도 지원되지 않아 긴 대기 시간 동안 아무것도 할 수 없다

## 배경 및 맥락

- 경로: 편집 > 목차 및 개요 / 원고
- 브라우저: 크롬 (Windows / Mac)
- 목차·개요 및 원고 생성 시 소요 시간이 길어 사용자가 해당 화면에서 대기해야 함
- 생성 중 다른 메뉴로 이동하거나 작업을 병행할 수 없는 상태

## 기대 결과

생성 요청 후 백그라운드에서 생성이 계속 진행되어, 사용자가 대기 중에도 다른 작업을 할 수 있다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (편집 > 목차 및 개요 / 원고 화면)
