## Problem Statement

편집 화면에서 초기 목차를 생성하는 사용자가 목차 생성 중 다른 단계로 화면을 이동했을 때, 목차 생성 표기가 이동한 화면에서도 계속 표시되며 생성이 중단되지 않는다

## 배경 및 맥락

- 경로: 편집
- 브라우저: 크롬 (Windows / Mac)
- 초기 목차 생성 중 다른 순서(단계)로 이동하면 이동한 화면에서도 목차 생성 중 표기가 지속됨
- 생성이 실제로 멈추는지 여부가 불명확하며, 사용자가 현재 상태를 파악하기 어려운 상태

## 기대 결과

다른 단계로 이동 시 목차 생성이 완전히 중단되고, 이동한 화면에서는 생성 표기가 표시되지 않는다
