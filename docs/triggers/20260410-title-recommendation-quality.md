## Problem Statement

제목 추천 기능을 사용하는 사용자가 제목 추천 결과를 확인했을 때, 추천 제목들이 평이한 수준으로만 생성되어 독자의 흥미를 끄는 강렬한 인상의 제목을 얻을 수 없다

## 배경 및 맥락

- 경로: 제목
- 브라우저: 크롬 (Windows / Mac)
- 현재 추천 제목들이 무난하고 평범한 수준에 머물러 있음
- 사용자가 원하는 임팩트 있는 제목을 추천 결과에서 찾기 어려워 직접 작성해야 하는 상태

## 기대 결과

제목 추천 결과에 독자의 흥미를 끌 수 있는 강렬하고 인상적인 제목 후보가 포함된다
