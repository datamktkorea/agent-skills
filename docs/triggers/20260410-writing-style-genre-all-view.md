## Problem Statement

기본정보 화면에서 문체·장르를 선택하는 사용자가 항목을 고르려고 할 때, 전체 목록을 한 번에 볼 수 없고 페이지를 넘겨가며 확인해야 한다

## 배경 및 맥락

- 경로: 기본정보 > 오른쪽 화면의 "문체", "장르" 영역
- 브라우저: 크롬 (Windows / Mac)
- 현재 문체와 장르 선택 UI가 페이지네이션 방식으로 구현되어 있어, 사용자가 전체 선택지를 파악하려면 여러 페이지를 순서대로 넘겨야 함

## 기대 결과

문체·장르 선택 화면에서 전체 항목을 한 번에 조회하고 선택할 수 있다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (기본정보 > 문체/장르 선택 화면)
