## Problem Statement

기본정보 화면을 사용하는 사용자가 왼쪽에서 문체를 선택했을 때, 오른쪽 문체 미리보기 영역에 선택한 문체로 변환된 예시 문장이 표시되지 않는다

## 배경 및 맥락

- 경로: 기본정보 > 오른쪽 화면의 "문체 미리보기" 영역
- 브라우저: 크롬 (Windows / Mac)
- 문체 미리보기 영역 자체는 존재하지만, 왼쪽에서 문체를 선택해도 해당 문체로 변환된 예시 문장이 동적으로 표시되지 않음

## 기대 결과

왼쪽에서 문체를 선택하면 오른쪽 미리보기 영역에 해당 문체로 변환된 예시 문장이 즉시 표시된다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (기본정보 > 문체 미리보기 화면)
