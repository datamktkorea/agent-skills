## Problem Statement

편집 화면에서 레이아웃을 설정하는 사용자가 레이아웃 설정을 변경했을 때, 원고의 스타일이 변경되지 않고 원고 페이지가 실제 용지 크기와 일치하지 않는다

## 배경 및 맥락

- 경로: 편집 > 원고 > 레이아웃
- 브라우저: 크롬 (Windows / Mac)
- 레이아웃 설정 기능은 존재하지만, 설정 변경이 원고 스타일에 반영되지 않음
- 원고 페이지 크기가 실제 출력 용지 크기와 일치하지 않아 편집 결과 예측이 어려운 상태

## 기대 결과

레이아웃 설정을 변경하면 원고 스타일이 즉시 반영되고, 원고 페이지가 실제 용지 크기와 일치하여 표시된다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (편집 > 원고 > 레이아웃 화면)
