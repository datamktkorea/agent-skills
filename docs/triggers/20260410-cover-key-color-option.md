## Problem Statement

표지를 작업하는 사용자가 키 컬러를 선택한 후 표지를 생성할 때, 선택한 키 컬러를 표지에 반영하는 옵션이 없어 키 컬러를 표지 디자인에 적용할 수 없다

## 배경 및 맥락

- 경로: 표지
- 브라우저: 크롬 (Windows / Mac)
- 사용자가 키 컬러를 설정할 수 있지만, 해당 컬러를 표지 생성에 연동하는 옵션이 존재하지 않음
- 표지 디자인에 브랜드 또는 작품의 키 컬러를 일관되게 적용할 수 없는 상태

## 기대 결과

표지 생성 시 사용자가 선택한 키 컬러를 표지 디자인에 반영할 수 있는 옵션이 제공된다
