## Problem Statement

에셋에서 파일 업로드를 사용하는 사용자가 10MB 이상의 파일을 선택한 후 추가하기 버튼을 클릭했을 때, 버튼이 동작하지 않는다 (아무런 피드백 없음)

## 배경 및 맥락

- 경로: 에셋 > 파일 업로드
- 브라우저: 크롬 (Windows / Mac)
- 10MB 이상의 파일 선택 후 추가하기 버튼을 클릭하면 아무런 반응이 없음
- 업로드 제한에 대한 안내 메시지나 오류 피드백 없이 묵묵히 실패함

## 기대 결과

10MB 이상의 파일 업로드 시도 시, 업로드가 정상 처리되거나 용량 제한 안내 메시지가 사전에 표시된다
