## Problem Statement

표지를 생성하는 사용자가 표지 생성 기능을 사용할 때, 앞표지·뒤표지만 생성되고 뒷날개·책등·앞날개는 생성할 수 없다

## 배경 및 맥락

- 경로: 기본정보 / 표지
- 브라우저: 크롬 (Windows / Mac)
- 현재 표지 생성 기능은 앞표지와 뒤표지만 지원함
- 실제 도서 제작에 필요한 뒷날개, 책등, 앞날개 구성요소는 생성 기능이 없는 상태

## 기대 결과

표지 생성 시 앞날개, 앞표지, 책등, 뒤표지, 뒷날개 전체 구성요소를 생성할 수 있다
