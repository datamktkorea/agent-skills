## Problem Statement

에셋 보관함에서 파일을 삭제하는 사용자가 휴지통 아이콘 클릭 후 취소·삭제 버튼 또는 모달 바깥 영역을 클릭했을 때, 삭제된 자료의 정보가 다시 표시되어 의도한 상태(원복 또는 삭제)로 돌아가지 않는다

## 배경 및 맥락

- 경로: 에셋 > 내 에셋 보관함
- 브라우저: 크롬 (Windows / Mac)
- 휴지통 클릭 시 삭제 확인 모달이 표시됨
- 모달에서 취소 버튼 클릭, 삭제 버튼 클릭, 또는 모달 바깥 영역 클릭 시 삭제된 자료의 정보가 재표시되는 비정상 동작 발생

## 기대 결과

- **취소 버튼 클릭**: 모달이 닫히고 원래 에셋 목록 화면으로 돌아간다
- **삭제 버튼 클릭**: 해당 자료가 즉시 삭제되고 삭제된 상태의 목록이 표시된다
- **모달 바깥 클릭**: 취소와 동일하게 원래 화면으로 돌아간다
