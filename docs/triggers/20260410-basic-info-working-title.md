## Problem Statement

기본 정보를 설정하는 사용자가 가제목을 미리 입력해두려고 할 때, 가제목을 입력할 수 있는 필드가 없어 입력할 수 없다

## 배경 및 맥락

- 경로: 기본 정보
- 브라우저: 크롬 (Windows / Mac)
- 기본 정보 설정 화면에 가제목 입력 항목 자체가 존재하지 않음
- 사용자가 작업 초기 단계에서 가제목을 기록해두고 싶어도 별도 메모 수단을 이용해야 하는 상태

## 기대 결과

기본 정보 설정 화면에서 가제목을 미리 입력하고 저장할 수 있다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (기본 정보 화면)
