## Problem Statement

표지를 작업하는 사용자가 레퍼런스 이미지 또는 현재 선택된 표지를 수정하려고 할 때, 선택된 이미지에 프롬프트 기반 수정을 적용할 수 없다

## 배경 및 맥락

- 경로: 표지
- 브라우저: 크롬 (Windows / Mac)
- 현재 표지 생성 기능은 있지만, 생성된 이미지 또는 레퍼런스 이미지를 기반으로 "ABC 추가해줘"와 같은 프롬프트로 이미지를 수정하는 기능이 없음
- 수정이 필요할 경우 처음부터 다시 생성해야 하는 상태

## 기대 결과

레퍼런스 이미지 또는 현재 선택된 표지에 프롬프트를 입력하면 해당 내용이 반영된 수정 이미지가 생성된다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (표지 화면)
