## Problem Statement

기본 정보 화면에서 문체 학습을 사용하는 사용자가 문체 학습하기 버튼을 클릭하고 파일을 업로드하려고 할 때, 파일 업로드 모달은 표시되지만 실제 문체 학습 기능이 구현되어 있지 않아 학습을 진행할 수 없다

## 배경 및 맥락

- 경로: 기본 정보
- 브라우저: 크롬 (Windows / Mac)
- "문체 학습하기" 버튼 클릭 시 파일 업로드 모달이 표시됨
- 그러나 실제 학습 처리 로직이 미구현 상태로, 파일을 업로드해도 문체 학습이 이루어지지 않음

## 기대 결과

파일을 업로드하면 해당 파일을 기반으로 문체 학습이 실행되고, 학습된 문체가 서비스에 반영된다
