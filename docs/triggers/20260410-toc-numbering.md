## Problem Statement

편집 화면에서 목차를 사용하는 사용자가 목차를 확인하려고 할 때, 목차 항목에 계층 번호(1, 1.1, 1.2, 1.2.1 등)가 표시되지 않아 구조를 한눈에 파악하기 어렵다

## 배경 및 맥락

- 경로: 편집 > 개요 > 목차
- 브라우저: 크롬 (Windows / Mac)
- 현재 목차에 번호 없이 항목 제목만 나열되어 있음
- 계층 구조가 시각적으로 구분되지 않아 복잡한 목차일수록 파악이 어려운 상태

## 기대 결과

목차 항목에 계층 번호(1, 1.1, 1.2, 1.2.1 등)가 표시되어 구조를 한눈에 파악할 수 있다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (편집 > 개요 > 목차 화면)
