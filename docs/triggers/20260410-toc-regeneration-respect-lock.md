## Problem Statement

편집 화면에서 목차를 관리하는 사용자가 특정 목차 항목을 잠근 상태에서 목차 재생성을 실행했을 때, 잠긴 목차 항목도 함께 재생성되어 잠금이 무시된다

## 배경 및 맥락

- 경로: 편집 > 개요
- 브라우저: 크롬 (Windows / Mac)
- 목차 항목에 잠금 기능이 존재하지만, '목차 재생성' 실행 시 잠긴 항목도 포함하여 전체가 재생성됨
- 사용자가 수동으로 수정·고정한 목차 항목이 재생성 후 사라지는 상태

## 기대 결과

목차 재생성 시 잠금 처리된 항목은 변경되지 않고 유지되며, 잠기지 않은 항목만 재생성된다

## 참고 자료
