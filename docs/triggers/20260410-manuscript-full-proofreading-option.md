## Problem Statement

편집 화면에서 원고 교정을 사용하는 사용자가 전체 원고에 교정을 적용하려고 할 때, 현재 위치한 챕터에만 교정이 적용되고 전체 원고 교정 옵션이 없어 일괄 적용할 수 없다

## 배경 및 맥락

- 경로: 편집 > 원고 > 원고
- 브라우저: 크롬 (Windows / Mac)
- 현재 교정 기능은 사용자가 위치한 챕터 단위로만 동작함
- 전체 원고에 교정을 적용하려면 챕터를 하나씩 이동하며 반복 실행해야 하는 상태

## 기대 결과

교정 요청 시 현재 챕터 또는 전체 원고 중 범위를 선택할 수 있는 옵션이 제공된다
