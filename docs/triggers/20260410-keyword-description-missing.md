## Problem Statement

기본 정보 화면에서 키워드를 설정하는 사용자가 키워드 영역에 입력하려고 할 때, 키워드가 무엇을 위한 것인지·어디에 사용되는지 설명이 없어 올바르게 활용할 수 없다

## 배경 및 맥락

- 경로: 기본 정보 > 키워드
- 브라우저: 크롬 (Windows / Mac)
- 키워드 입력 영역은 존재하지만 해당 키워드의 목적, 용도, 적용 범위에 대한 안내 문구가 전혀 없음
- 사용자가 어떤 키워드를 입력해야 하는지, 입력한 키워드가 어디에 반영되는지 알 수 없는 상태

## 기대 결과

키워드 영역에 목적과 사용처를 안내하는 설명이 제공되어, 사용자가 키워드를 올바르게 이해하고 활용할 수 있다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (기본 정보 > 키워드 화면)
