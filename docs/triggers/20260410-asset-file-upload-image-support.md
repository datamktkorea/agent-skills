## Problem Statement

에셋 파일 업로드를 사용하는 사용자가 이미지를 업로드하려고 할 때, 이미지 파일을 업로드하는 기능이 없어 업로드할 수 없다

## 배경 및 맥락

- 경로: 에셋 > 파일 업로드
- 브라우저: 크롬 (Windows / Mac)
- 현재 파일 업로드 기능에서 이미지 파일 형식이 지원되지 않음

## 기대 결과

에셋 파일 업로드 기능에서 이미지 파일을 업로드할 수 있다
