## Problem Statement

편집 화면에서 개요를 작업하는 사용자가 개요 또는 설명을 재작성하려고 버튼을 클릭했을 때, 버튼에 기능이 연결되어 있지 않아 재작성이 실행되지 않는다

## 배경 및 맥락

- 경로: 편집 > 개요 > 개요
- 브라우저: 크롬 (Windows / Mac)
- 개요 또는 설명 재작성 버튼이 UI에 존재하지만 클릭해도 아무런 동작이 발생하지 않음
- 버튼과 실제 기능 간 연결이 미구현된 상태

## 기대 결과

재작성 버튼 클릭 시 개요 또는 설명이 재작성된다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (편집 > 개요 > 개요 화면)
