## Problem Statement

에셋에서 파일을 업로드하는 사용자가 이미 업로드된 파일과 동일한 파일을 다시 업로드할 때, 중복 업로드가 차단되지 않고 동일한 파일이 여러 번 업로드된다

## 배경 및 맥락

- 경로: 에셋 > 파일 업로드
- 브라우저: 크롬 (Windows / Mac)
- 동일한 파일을 반복 업로드해도 아무런 경고나 차단 없이 업로드가 완료됨
- 중복 파일이 누적되어 에셋 관리가 어려워지는 상태

## 기대 결과

이미 업로드된 파일과 동일한 파일을 업로드 시도할 경우, 업로드가 차단되거나 중복 경고 메시지가 표시된다
