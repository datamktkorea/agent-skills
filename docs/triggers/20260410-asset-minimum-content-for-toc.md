## Problem Statement

에셋에서 목차 생성을 사용하는 사용자가 텍스트를 짧게 입력한 후 목차 생성을 시도했을 때, 최소 입력량 기준 없이 목차 생성 단계에 접근할 수 있지만 실제 목차가 생성되지 않는다

## 배경 및 맥락

- 경로: 에셋
- 브라우저: 크롬 (Windows / Mac)
- 텍스트를 짧게 입력한 상태에서도 목차 생성 단계까지 진행이 가능함
- 그러나 실제로 목차는 생성되지 않고 실패하는 상태
- 목차 생성에 필요한 최소 에셋량이 정의되어 있지 않아 사용자가 헛수고하게 됨

## 기대 결과

목차 생성에 필요한 최소 에셋량 기준이 설정되고, 기준 미달 시 목차 생성 단계 진입 전에 사전 안내가 표시된다
