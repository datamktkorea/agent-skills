## Problem Statement

기본 정보를 설정하는 사용자가 어미를 설정하려고 할 때, 어미를 선택할 수 있는 옵션이 없어 설정할 수 없다

## 배경 및 맥락

- 경로: 기본 정보
- 브라우저: 크롬 (Windows / Mac)
- 기본 정보 입력란에 어미 선택 항목이 존재하지 않음
- 사용자가 원하는 어미(예: ~다체, ~요체 등)를 지정해두고 싶어도 별도 수단이 없는 상태

## 기대 결과

기본 정보 입력란에서 어미 옵션을 선택하고 저장할 수 있다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (기본 정보 화면)
