## Problem Statement

웹 리서치를 사용하는 사용자가 검색 결과에서 미리보기를 클릭했을 때, 해당 사이트 화면이 일부만 렌더링된다

## 배경 및 맥락

- 경로: 에셋 > 웹 리서치
- 브라우저: 크롬 (Mac / Windows)
- 검색 결과 목록에서 미리보기를 클릭하면 사이트 전체가 아닌 일부만 렌더링되는 상태로 표시됨

## 기대 결과

미리보기 클릭 시 해당 사이트의 전체 렌더링 화면이 정상적으로 표시된다

## 참고 자료

- 스크린샷: 첨부 이미지 참고 (에셋 > 웹 리서치 화면)
